# FastAPI TodoApp

A **Todo Management Application** built as a hands-on learning project to strengthen my skills in **REST API development and backend engineering with FastAPI**.

**[Live Demo](https://fast-api-rsi1.onrender.com/auth/login-page)** · **[Repository](https://github.com/Umais-Ah/FAST-API)**

## Features

- User registration and JWT-based authentication
- Create, view, update, and delete personal tasks
- Set task priorities and track completion
- Web interface integrated with FastAPI endpoints

## Tech Stack

**Backend:** Python, FastAPI, Pydantic, SQLAlchemy  
**Frontend:** HTML, CSS, JavaScript, Jinja2  
**Other:** Alembic, Pytest, Render

## Learning Focus

RESTful API design, authentication, database integration, request validation, automated testing, and application deployment.
